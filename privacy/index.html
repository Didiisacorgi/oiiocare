English summary： oiioCare collects only conversation audio, transcripts, and emotion tags you provide—never ambient background sound—encrypts them, does not use them for model training by default, and lets you export, delete, or withdraw consent at any time.

oiioCare 是饮食与情绪记录工具（聊天 / 拍照 / 语音记一餐与感受）。它不是诊疗或医疗器械，不提供诊断、治疗或疗效保证。本页说明我们处理什么、为什么处理，以及你如何管理自己的资料。

一、我们收集什么

  1. 账号信息：通过 Sign in with Apple 等登录获得的标识与邮箱（以你授权范围为限）。
  2. 记录内容：你主动提交的文字、餐图、情绪标签、份量，以及分析反馈所需的最小上下文；记录附带来源标识（如 ios / web / android）。
  3. AI 语音相关（仅在你使用语音功能时）：
    • 收集范围：仅「对话音频」（你对着产品说出的那一段）、由该音频生成的「转写文本」、以及你确认或系统生成的「情绪标签」。
    • 明确不收集：背景环境音、持续监听、未触发录音时的麦克风数据、通讯录、短信。
    • 录音仅在你点击语音并开始说之后开始，你结束或取消即停止。
  4. 技术日志：设备类型、浏览器 / App 版本、粗略地区、错误日志，用于安全与排障；不含完整餐图或完整语音原文进入公开日志。

二、我们如何使用

用于：为你提供记录、转写、分析反馈与跨端同步；保障安全与防滥用；按你的指示导出或删除。

不用于：向第三方出售个人数据。默认不用于训练通用或第三方 AI 模型（见第五节）。未登录时的示例对话只在页面展示，不会写入用户数据库。

三、存储与安全

  1. 传输：全程 HTTPS / TLS。
  2. 存储：静态加密（服务端加密存储）；访问按账号隔离，员工无常规权限浏览你的语音与餐图。
  3. 服务器位置：国内用户数据优先存放于中国境内合规云区域；海外用户数据存放于业务所在地的合规云区域。具体可用区域以产品内或本页更新说明为准；跨境传输将依法告知并取得必要同意。
  4. 备份：仅用于灾难恢复，受同等加密与访问控制。我们可能使用云存储与推理服务商（如数据库 / 托管 / 转写），受合同约束仅可按指示处理。

四、保留期限

  1. 语音原始音频：自收集之日起保留 30 天，期满自动删除；你可随时提前删除。
  2. 转写文本与情绪标签：默认保留 12 个月，或至你注销 / 删除相关记录之日（以较早者为准）；你可随时删除单条或全部。
  3. 账号注销后：我们将在合理期限内删除或匿名化你的个人数据，法律要求保留的除外。

五、是否用于模型训练

  1. 默认：你的语音原始音频、转写文本、情绪标签与餐图，不用于训练 oiioCare 或任何第三方通用模型。
  2. 若未来拟用于改进模型：将单独弹窗说明目的、范围与影响，需你主动同意；你可随时在设置中关闭；关闭后新数据立即停止用于训练，已用于训练的处理方式将在弹窗中说明。
  3. 关闭同意或拒绝弹窗，不影响你继续使用基本记录功能（可能无法享受需训练改进的可选能力）。

六、第三方共享

  1. 我们不出售你的个人数据。
  2. 仅在以下情况提供必要数据给处理者：云存储、转写 / 分析推理服务商——受合同约束，仅可按指示处理，不得留作自有训练语料（除非你按第五节另行同意）。
  3. 无其他第三方共享，除非法律、监管或司法程序要求；在法律允许范围内我们将通知你。

七、你的权利与路径

  1. 查阅与导出：在 App / 网页「设置 — 数据与隐私」申请导出；或发送邮件至 orangewang@oiiocare.com。我们将在验证身份后的合理期限内提供常用格式。
  2. 删除：可删除单条记录、语音或全部数据；注销账号见同页「注销」。删除记录时，对应对话与反馈一并删除，不保留「幽灵」汇总。
  3. 撤回同意：可在设置关闭麦克风 / 语音功能、关闭训练相关同意；撤回不影响撤回前基于同意的处理合法性。
  4. 更正：可编辑记录中的文字、份量与情绪标签。
  5. 投诉：发送至 orangewang@oiiocare.com。

八、未成年人

  1. 13 岁以下：不主动收集个人信息；若发现误收集，将尽快删除。
  2. 13–18 岁：须在监护人同意下使用；监护人可联系我们协助查阅、删除或撤回同意。

九、Web 与 App 共用账号

使用相同 Apple 账号登录后，Web 和 App 会对应到同一 oiioCare 用户。记录附带来源角标，来源不会被静默改写。退出后本机 Web 会话失效；撤销 Apple 授权后，需重新授权才能继续访问。

十、Cookie 与同类技术

网站可能使用必要 Cookie 维持登录与语言偏好；你可通过浏览器限制，但可能影响登录态。

十一、政策更新

更新时将在本页公布生效日期；重大变更（如训练用途、跨境存储地点变更）将通过产品内通知或弹窗提示。涉及新的同意事项时，仍将单独征求同意。

十二、联系我们

邮箱：orangewang@oiiocare.com
